# Codex 开发文档包（缴费服务更新版）

本目录用于直接交给 Codex 开发“加装电梯后期管理平台”。当前版本覆盖三类端：

1. **业主微信小程序**：缴费、报修、维保记录、装修登记、公告、企业介绍、个人中心。
2. **维修师傅移动端**：工单接单/处理、维修进度、维修结果与完工照片、维保 PDF 上传归档、消息与个人中心。
3. **管理员 PC 后台**：工作台、报修工单、维保档案、装修登记、公告、企业介绍、账号权限、系统设置、缴费服务管理。

## 文件说明

- `需求.md`：原始业务需求基准。
- `UI_SPEC.md`：最新版 UI/组件/状态/权限规范，已恢复并细化缴费服务。
- `interaction.md`：三端交互、页面跳转、状态机、支付/报修/维保/装修流程。
- `PROJECT_STRUCTURE.md`：小程序 + 管理后台 + 服务层的推荐目录、模型、接口和 Mock 结构。
- `CODEX_PROMPT.md`：可直接交给 Codex 的主开发提示词与验收标准。

## 本次更新重点

### 1. 恢复“缴费服务”

原先文档曾临时删除缴费功能；**该限制已作废**。当前需求明确恢复：

- 首页增加“缴费服务”。
- 支持待缴、欠费、已缴、全部账单。
- 支持账单详情和费用明细。
- 支持微信支付。
- 支持缴费记录。
- 支持缴费后在线申请收据。
- 个人中心增加“我的缴费 / 缴费记录 / 我的收据”。

### 2. 每户收费金额可以不同

管理员不能只维护一个统一金额。收费模型必须支持：

```text
同一收费周期
  ├─ 1栋101室：¥388.00
  ├─ 1栋102室：¥428.00
  └─ 1栋103室：¥346.00
```

每户还可以拥有不同的费用明细。

### 3. 管理员支持批量上传收费数据

PC 后台增加“缴费服务管理”，支持：

- 收费项目配置。
- 按户收费标准管理。
- Excel / CSV 批量上传。
- 导入预览、校验、错误行提示。
- 生成/更新账单。
- 欠费预警和催缴。
- 缴费记录和对账。
- 收据申请处理。

### 4. 电梯后期管理费可包含的费用项

费用项应做成**后台可配置**，并支持但不限于：

- 电梯相关电费。
- 电梯大、小零件费。
- 维护保养费。
- 人工费。
- 通讯费。
- 年审费用。
- 清洁费。
- 保险费（如人身电梯意外保险、电梯自然灾害险）。
- 电梯安全管理员相关服务费（特种设备管理员证）。

不要把上述项目硬编码成固定必收项；管理员可以按项目实际情况启用、停用、调整名称和金额。

## UI 设计基准

视觉继续采用当前确认的：

```text
蓝白主色 + 浅灰背景 + 白色圆角卡片 + 弱阴影
```

最新 UI 与 `需求.md` 冲突时遵循：

```text
1. 用户最新明确确认
2. 需求.md 的业务边界
3. UI_SPEC.md
4. interaction.md
5. UI 参考图
```

注意：若某张生成的 UI 图偶然出现“安全介绍”等未在需求中确认的独立模块，**不得据此删除装修登记或新增核心业务**。业主端核心入口应保留缴费、报修、维保、装修、公告、企业介绍、个人中心。
