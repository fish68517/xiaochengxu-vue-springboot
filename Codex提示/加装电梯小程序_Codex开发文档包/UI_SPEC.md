# 5. 缴费服务 UI（业主端核心）

## 5.1 业务原则

**每户账单金额允许不同。**

例如：

```text
1栋101室 → ¥388.00
1栋102室 → ¥428.00
1栋103室 → ¥346.00
```

同一收费周期内，每户的费用项目和金额也可以不同。

前端不得通过统一公式自行推导金额，必须展示后台下发的账单金额与明细。

## 5.2 缴费账单列表

页面标题：

```text
缴费服务
```

Tab：

```text
全部 | 待缴 | 欠费 | 已缴
```

账单卡片字段：

```text
房屋
账单名称
收费周期
账单生成时间
应缴金额
状态
去缴费 / 查看详情
```

状态：

```ts
type BillStatus =
  | 'PENDING'   // 待缴
  | 'OVERDUE'   // 欠费
  | 'PAID'      // 已缴
  | 'CLOSED';   // 已关闭
```

状态色：

- 待缴：红/橙
- 欠费：红
- 已缴：绿
- 已关闭：灰

## 5.3 缴费详情 / 费用明细

顶部卡：

```text
当前房屋
账单名称
收费周期
待付/已付金额
账单状态
```

费用明细表：

```text
费用项                     金额
--------------------------------
电梯相关电费               80.00
电梯零件费                 50.00
维护保养费                 90.00
人工费                     40.00
通讯费                     10.00
年审费用                   20.00
清洁费                     18.00
保险费                     30.00
安全管理员服务费           50.00
```

上述只作为 UI 示例，实际项目由后台配置和按户账单数据决定。

底部：

```text
合计金额：¥388.00                立即缴费
```

已缴账单不显示“立即缴费”，改为：

```text
查看缴费凭证 / 申请收据
```

## 5.4 费用项支持范围

管理员可配置但不限于：

1. 电梯相关电费
2. 电梯大、小零件费
3. 维护保养费
4. 人工费
5. 通讯费
6. 年审费用
7. 清洁费
8. 保险费
9. 电梯安全管理员相关服务费
10. 其他自定义费用项

每个费用项应支持：

```text
名称
说明
是否启用
默认金额（可选）
排序
备注
```

默认金额不能覆盖“按户自定义金额”。

## 5.5 缴费记录

页面：

```text

```

```text

```

记录字段：


## 5.6 微信支付 UI 状态

点击“立即缴费”后：

```text
创建支付订单
↓
拉起微信支付
↓
支付成功 / 用户取消 / 支付失败
```

必须有：

- 防重复点击。
- 支付中 Loading。
- 支付结果查询。
- 支付成功页/Toast。
- 支付失败可重试。

前端只展示后端返回金额，不允许前端修改最终支付金额。

## 5.7 收据申请

缴费成功后提供：

```text
申请收据
```

建议表单：

```text
关联缴费记录
收据抬头/姓名
联系电话
备注（可选）
```

状态：

```text
待处理 | 已开具 | 已驳回
```

若业务只要求“收据”而非“发票”，UI 文案统一使用“收据”，不要擅自改成“发票”。

```text
SUPER_ADMIN
ADMIN
TECHNICIAN
OWNER
```

建议后台采用 RBAC：

```text
角色 → 权限 → 菜单/按钮/API
```

管理员可以配置维修师傅账号和权限范围。

```text
Loading
空数据

无权限
提交中
```
