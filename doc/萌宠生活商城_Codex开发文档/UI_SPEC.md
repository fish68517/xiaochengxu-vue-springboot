# UI_SPEC.md

# 萌宠生活商城 UI 设计规范

## 1. 产品视觉定位

关键词：

- 温暖
- 治愈
- 萌宠
- 轻电商
- 活动感
- 信任感
- 易操作

整体采用当前 UI 稿的 **奶油白 + 暖橙色 + 淡绿色点缀**。

---

## 2. 全局视觉规范

### 2.1 主色

```text
Primary Orange: #FF6A00
Primary Light:  #FFF1DC
Background:     #FFF9F1
Card:           #FFFFFF
Text Primary:   #2B211B
Text Secondary: #8B8078
Success:        #59B866
Warning:        #F6A623
Border:         #F1E3D3
```

### 2.2 圆角

```text
大卡片：20rpx ~ 28rpx
按钮：  40rpx ~ 48rpx
标签：  12rpx ~ 18rpx
图片：  20rpx
```

### 2.3 阴影

使用非常轻的暖色阴影：

```css
box-shadow: 0 8rpx 30rpx rgba(120, 80, 30, 0.08);
```

不使用强烈黑色投影。

### 2.4 字体层级

```text
页面标题：32~36rpx / SemiBold
模块标题：28~32rpx / SemiBold
商品名称：28rpx / Medium
正文：24~26rpx
辅助信息：22~24rpx
价格：34~42rpx / Bold / 橙色
```

### 2.5 Button

主按钮：

```text

白色字体
高度 88rpx
满圆角
```

次按钮：

```text
白底
橙色边框
橙色文字
```

支付按钮：

```text

文案：微信支付
```

# 3. Bottom TabBar

推荐：

```text
首页
商城
活动
购物车
我的
```

说明：

- “活动”入口承载抽奖活动，而不是把抽奖做成整个产品的核心。
- “萌宠详情”不是 TabBar 页面，由商城卡片进入。
- “我的萌宠”位于“我的”内部，也可根据设计稿把“我的”页面直接命名为“我的萌宠”。

# 7. 页面 4：抽奖活动页

这是新版本最重要的改动页面。

## 7.1 Header

```text
抽奖活动
春日萌宠抽奖季
活动通知已发布，快来报名参加
```

## 7.2 活动状态卡

展示：

```text
状态：报名中

报名时间：
2026-05-16 10:00
~
2026-05-23 23:59

开奖时间：
2026-05-24 14:00

距离开奖：
02天 18时 24分 36秒
```

注意：

倒计时以后端时间为准。

## 7.3 奖品预览

示例：

```text
一等奖
萌宠用品礼包
5份

二等奖
爬宠专区优惠券
10份

三等奖
萌宠用品优惠券
20份

参与奖
萌宠积分
100份
```

不建议把活体宠物直接作为随机奖品。

## 7.4 参与人数

```text
已有 1286 人报名
```

显示：

- 总人数
- 最近报名头像（最多 8~10 个）
- “查看参与人数”

## 7.5 CTA 状态

未报名：

```text
[立即报名参加]
```

已报名：

```text
✓ 已成功报名
等待开奖
```

报名结束：

```text
报名已截止
```

开奖后：

```text
查看开奖结果
```

## 7.6 活动规则

列表式：

1. 管理员发布活动；
2. 用户在报名时间内参加；
3. 报名成功后获得参与资格；
4. 到达开奖时间服务端自动开奖；
5. 中奖名单公开；
6. 中奖用户联系管理员领奖。

# 12. UI 实现约束

Codex 开发时：

1. 不自行改变页面信息架构；
2. 优先拆通用组件；
3. 不把所有页面写进单一 Vue 文件；
4. 使用 TypeScript 类型；
5. 所有列表必须支持真实 API 数据替换；
6. 所有按钮必须有 loading/disabled 状态；
7. 所有用户输入必须校验；
8. 后端未完成前可以使用 Mock 数据，但接口层必须独立；
9. 禁止通过 `Math.random()` 在前端产生真实抽奖结果；
10. 页面必须适配主流微信小程序屏幕宽度。
