# 品牌商品资源设计

## 1. 本次范围与现状

- 仅改阿里云 `game-service`、管理员 H5 和客户端 H5/微信小程序，不修改腾讯云目录。
- 管理员目前只能填写图片 URL；品牌 Banner 和商品素材附件 ID 暂时从编辑界面隐藏，历史数据保留，不能因隐藏而清空。
- 客户端目前携带构建品牌 Code 查询商品，只展示单品牌。新增公开聚合目录，展示所有启用品牌的上架商品；订单、钱包和后台权限仍保持现有隔离。

## 2. 支付凭据引用

不将所有新品牌强制填为 `secret://xinghe/wechat-pay/production`。

技术人员应在 `game-service/private-config/wechat-pay.json`（或已配置的 `WECHAT_PAY_CONFIG_MAP`）中，为对应环境、品牌 Code 添加映射，后台填写该项的 `secretRef`。同一经营主体、同一商户可按已配置映射复用引用；不同主体不得共用。证书、APIv3 密钥仍只放云端私有配置，不上传至公开图片存储。

例如 `demo-a` 可继续使用 `secret://xinghe/wechat-pay/production`；新增 `brand-b` 不能仅复制文本，必须另有 `production.brand-b` 映射，并核对主体、商户号、AppID 关联和回调地址。后台字段旁显示以上说明，不自动替客户开通支付。

## 3. 资源上传最小实现

新增管理员专用 `uploadCatalogImage` 接口，与完成凭证、身份证的 `uploadFile` 分开。

1. 管理员选择本地 PNG/JPEG/WebP 图片，显示上传中状态；单张最大 1 MiB，商品最多 9 张。
2. 管理员 H5 读取图片，调用有登录、角色及品牌范围校验的云函数。云端再次检查长度、文件签名和类型，生成随机文件名上传阿里云公开资源目录。
3. 返回长期资源 URL，填入原有 `logo` / `images` 字段；保存品牌/商品后生效。提供预览、移除和失败提示；上传期间禁止保存或切换正在编辑的对象。
4. 新品牌先填写品牌 ID 即可上传 Logo，无需先建立品牌。只有有权管理该品牌的管理员能上传。
5. 不接受任意远程 URL 让服务端下载，不把客户端临时 blob 路径存库，不把私有凭证转成公开素材。
6. 从表单移除图片只解除引用，不删除云端对象，避免破坏历史订单图片；未保存的上传可能形成孤立资源，后续运维核对引用后清理。

选择云函数中转是本次管理员低频、小图片上传的简化实现：可统一鉴权和文件验证。限制 1 MiB 是为了给 Base64 编码和请求字段预留空间；阿里云调用请求有大小限制。大图/批量上传不在本次范围，后续应改用授权直传。

官方依据：[云存储上传 API](https://doc.dcloud.net.cn/uniCloud/storage/dev)、[云函数调用限制](https://doc.dcloud.net.cn/uniCloud/cf-callfunction.html)。

## 4. 全品牌商品目录

- 新增 `listCatalogProducts` / `getCatalogProduct` 公开接口，不修改现有单品牌 `listProducts/getProduct` 契约，避免影响后台及旧调用。
- 只返回品牌状态 ON/ACTIVE 且商品 ON 的记录；采用分页读取，避免云数据库默认条数截断。
- 返回明确的公开字段白名单，附带 `brandId/brandCode/brandName/brandLogo`；不返回支付引用、商户绑定、内部佣金规则和素材附件信息。
- 首页和分类页使用聚合接口；商品卡片顶部标记品牌名称，详情页显示同样标记。现有启动品牌仍负责顶部主题，不再决定商品列表范围。
- 跨品牌浏览不等于跨 AppID 下单。当前身份仍由启动品牌小程序生成，非当前品牌商品的详情页明确提示“请前往该品牌小程序下单”；不得把全品牌权限授予客户会话以绕过支付校验。统一小程序跨品牌结算需要另行设计客户身份和支付渠道归属，本次不隐式扩展。
- `brand-b` 即使填写演示 AppID，也可展示已上架商品，但不能据此宣称真实微信登录/支付已开通。

## 5. 实施与验收

阶段一：实现公开图片上传接口和复用图片选择组件，接入品牌 Logo 与商品图片；隐藏 Banner、素材 ID 输入，保留旧值；补充支付引用填写说明。

阶段二：实现公开聚合商品接口、卡片和详情品牌标签；保留原有下单校验并提示跨品牌入口边界；执行针对性回归与三端构建。

验收：新增/编辑品牌可上传并保存 Logo；商品可上传、预览、移除多张图片，刷新后仍显示；保存时不清空历史 Banner/素材 ID；停用品牌或下架商品不在目录中；不同品牌商品显示正确归属；工作人员/客服不能调用管理员图片接口；错误格式和超限图片被拒绝。

部署：上传新版阿里云 `game-service`，上传 `catalog_assets.schema.json` 并创建 `catalog_assets` 集合（仅云函数读写，禁止客户端直读写），重新发布 admin 和 client H5，重新构建上传 client 微信小程序。确认公开资源域名在小程序需要的合法域名配置中，真机检查图片。无需修改 workbench；本次不自动部署、不修改真实品牌支付文件、不提交真实订单或支付。

## 6. 代码落点

- `code/apps/admin/src/components/CatalogImagePicker.vue`：复用选择、上传、预览、移除组件，上传期间锁定保存与编辑对象切换。
- `code/apps/admin/src/pages/brands/index.vue`：Logo 上传、支付提示、保留隐藏 Banner 与资产配置。
- `code/apps/admin/src/pages/products/index.vue`：商品图片上传，保留隐藏素材附件值。
- `code/apps/client/uniCloud-aliyun/cloudfunctions/game-service/lib/catalog.cjs`：公开目录字段白名单、分页及图片验证上传。
- `code/apps/client/uniCloud-aliyun/database/catalog_assets.schema.json`：图片来源与品牌归属登记，不与私有附件混用。
- `code/apps/client/src/api.js`、`components/ProductCard.vue`、`pages/product/detail.vue`：聚合目录、品牌标签及跨品牌下单提示。

当前新增接口只落在阿里云实现中；本地 HTTP 模拟后端未同步新增接口。联调应使用生产构建对应的 uniCloud 通道。
