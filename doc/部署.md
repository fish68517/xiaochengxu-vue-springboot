# 电梯安装预约维修小程序——腾讯云 Windows Server 部署指南

> 适用项目：当前仓库中的 `miniprogram/`、`admin-web/`、`backend/`。  
> 适用服务器：腾讯云轻量应用服务器 Windows Server（例图为 Windows Server 2022/2025 风格的 TAT/OrcaTerm PowerShell）。  
> 目标：先完成可公网查看的部署验证，再补域名、备案、HTTPS、正式微信登录和微信支付。

## 1. 先说明例图中的目录

例图当前提示符是：

```powershell
PS C:\Windows\system32\config\systemprofile>
```

这不是项目目录，也不是异常。腾讯云自动化助手 TAT 在 Windows 实例中默认以 `System` 用户执行，官方文档给出的默认执行目录是：

```text
C:\Program Files\qcloud\tat_agent\workdir
```

因此终端可能显示 `systemprofile` 或 TAT 工作目录。**不要把项目部署到 `C:\Windows`、`System32` 或 `systemprofile` 中。**本项目统一部署到：

```text
C:\elevator-service
```

腾讯云官方说明：TAT 可以在无需远程桌面密码登录的情况下执行 PowerShell 命令；Windows 默认执行用户是 System。  
参考：[TAT 免登录执行命令](https://cloud.tencent.com/document/product/1340/51946)、[TAT 与本地脚本执行差异](https://cloud.tencent.com/document/product/1340/118990)。

## 2. 本项目到底哪些内容需要部署

### 2.1 上传到服务器的内容

本地执行打包脚本后，只需向服务器上传一个文件：

```text
release\elevator-release-年月日-时分秒.zip
```

该 ZIP 内部包含：

```text
backend\                       FastAPI 后端源代码
├─ app\
├─ alembic\
├─ alembic.ini
└─ requirements.txt

admin\                         已构建的管理员后台静态文件
├─ index.html
└─ assets\

deploy\windows\
├─ install-server.ps1          服务器一键安装/更新脚本
└─ health-check.ps1            健康检查脚本
```

### 2.2 不上传到服务器的内容

以下内容不需要上传：

```text
admin-web\node_modules\
miniprogram\node_modules\
backend\.venv\
.runtime\
Codex提示\
UI 设计图、演示视频
本地 development 的 .env
任何密码、AppSecret、微信支付私钥或证书
```

### 2.3 微信小程序代码放在哪里

微信小程序不是把前端文件放到 Windows 网站目录中。另一个本地生成的文件：

```text
release\elevator-mp-weixin-年月日-时分秒.zip
```

应在本地电脑解压，然后用微信开发者工具导入、测试、上传版本和提交审核。服务器只负责：

```text
HTTPS API
MySQL 数据库
报修图片 / 维保 PDF 等文件存储
管理员 PC 后台
微信支付回调与通知接口（正式能力完成后）
```

## 3. 最简单的部署方式

整个过程只有三步：

```text
本地一键打包
→ OrcaTerm 上传一个 ZIP
→ TAT 粘贴一段命令执行
```

## 4. 第一步：在本地电脑一键打包

打开本地 PowerShell：

```powershell
cd "E:\bishe27\小程序\电梯维修"
Set-ExecutionPolicy -Scope Process Bypass
.\deploy\windows\build-release.ps1
```

脚本会自动：

1. 构建 `admin-web`，后台 API 地址使用同域 `/api`。
2. 构建 `mp-weixin` 微信小程序代码。
3. 去除 `node_modules`、`.venv`、缓存和本地密钥。
4. 在 `release\` 下生成服务器 ZIP 和微信小程序 ZIP。

如果依赖已经安装，希望跳过 `npm install` 检查，可执行：

```powershell
.\deploy\windows\build-release.ps1 -SkipInstall
```

## 5. 第二步：把服务器 ZIP 上传到腾讯云

### 推荐：使用例图中的 OrcaTerm 上传

1. 在腾讯云轻量应用服务器控制台进入该实例。
2. 单击“登录/免密登录”，进入例图中的 OrcaTerm PowerShell。
3. 使用 OrcaTerm 顶部菜单中的“上传文件”。
4. 上传本地最新的：

```text
release\elevator-release-年月日-时分秒.zip
```

5. 服务器目标目录填写：

```text
C:\deploy
```

如果目录不存在，先在终端执行：

```powershell
New-Item -ItemType Directory -Path C:\deploy -Force
```

腾讯云说明 OrcaTerm 支持上传/下载文件；TAT 也有“上传文件”公共命令，但 TAT 控制台直接上传的单文件内容限制为 36KB，完整发布 ZIP 通常超过该限制，因此大 ZIP 优先使用 OrcaTerm 上传。  
参考：[TAT 上传文件到云服务器](https://cloud.tencent.com/document/product/1340/72845)、[OrcaTerm 登录说明](https://cloud.tencent.com/document/product/1207/44642)。

### 如果 OrcaTerm 没有上传按钮

可选方案：

1. 把发布 ZIP 上传到腾讯云 COS。
2. 生成一个短期有效的私有下载链接。
3. 在 TAT PowerShell 中执行：

```powershell
New-Item -ItemType Directory -Path C:\deploy -Force
Invoke-WebRequest -Uri "这里替换为COS短期下载链接" -OutFile "C:\deploy\elevator-release.zip"
```

不要在文档、Git 或聊天记录中长期保存带签名的 COS 私有链接。

## 6. 第三步：在 TAT 中执行一键部署

进入：

```text
腾讯云轻量应用服务器控制台
→ 当前实例
→ 执行命令
→ 执行命令
```

参数选择：

| 参数 | 填写内容 |
|---|---|
| 命令类型 | PowerShell |
| 执行用户 | System（默认） |
| 执行路径 | 保持默认即可 |
| 超时时间 | 3600 秒 |

粘贴下面整段命令：

```powershell
$ErrorActionPreference = 'Stop'
$zip = Get-ChildItem -LiteralPath C:\deploy -Filter 'elevator-release-*.zip' |
    Sort-Object LastWriteTime -Descending |
    Select-Object -First 1
if (-not $zip) { throw 'C:\deploy 下没有找到 elevator-release-*.zip' }

$unpack = 'C:\deploy\elevator-release-unpacked'
if (Test-Path $unpack) {
    Remove-Item -LiteralPath $unpack -Recurse -Force
}
Expand-Archive -LiteralPath $zip.FullName -DestinationPath $unpack -Force

& "$unpack\deploy\windows\install-server.ps1" `
    -PackageRoot $unpack `
    -InstallRoot 'C:\elevator-service' `
    -SeedDemoData
```

首次执行大约需要数分钟，取决于服务器网络。脚本自动完成：

```text
安装 Python 3.12
安装 MySQL 8.0.36
创建 elevator_service 数据库和独立应用账号
安装 Nginx
创建 Python venv 并安装 requirements.txt
执行 Alembic migration
可选写入演示数据
部署管理员后台
注册后端和 Nginx 开机启动任务
放通 Windows 系统防火墙 80/443
执行 /api/health 健康检查
```

TAT 会根据 PowerShell 退出码显示成功或失败；腾讯云文档说明 TAT 默认超时为 60 秒、最大可设为 86400 秒，所以首次安装应把超时改为 3600 秒。TAT 输出超过 24KB 时会被截断，完整日志仍保存在服务器目录中。  
参考：[TAT 执行差异与超时/输出限制](https://cloud.tencent.com/document/product/1340/118990)、[TAT 产品限制](https://cloud.tencent.com/document/product/1340/52695)。

## 7. 腾讯云控制台还必须放行端口

脚本只能配置 Windows 内部防火墙，不能替你修改腾讯云轻量应用服务器的实例防火墙。

在实例详情页选择“防火墙”，增加：

| 协议 | 端口 | 来源 | 用途 |
|---|---:|---|---|
| TCP | 80 | `0.0.0.0/0` | 第一次用公网 IP 验证后台 |
| TCP | 443 | `0.0.0.0/0` | 域名 HTTPS 正式访问 |

不要对公网开放：

```text
3306    MySQL，仅允许服务器本机 127.0.0.1
8010    FastAPI，仅允许 Nginx 从本机反向代理
```

腾讯云的实例防火墙和 Windows 系统防火墙是两层独立规则，两边都必须允许相应端口。  
参考：[轻量应用服务器管理防火墙](https://cloud.tencent.com/document/product/1207/89060)。

## 8. 部署成功后怎么访问

先在服务器内部检查：

```powershell
cd C:\elevator-service
.\current\deploy\windows\health-check.ps1
```

注意：健康检查脚本实际位于发布包 `deploy\windows` 中；服务器安装脚本主要使用内置健康检查。也可以直接执行：

```powershell
Invoke-RestMethod http://127.0.0.1/api/health
Get-ScheduledTask ElevatorBackend, ElevatorNginx
Get-NetTCPConnection -State Listen -LocalPort 80,8010,3306
```

再在本地浏览器访问：

```text
http://服务器公网IP/
http://服务器公网IP/docs
```

如果服务器内部健康检查成功，但公网打不开，优先检查腾讯云实例防火墙是否放通 TCP 80。

## 9. 服务器最终需要的目录和文件

一键脚本完成后，服务器应有以下结构：

```text
C:\elevator-service\
├─ current\
│  ├─ backend\
│  │  ├─ app\
│  │  ├─ alembic\
│  │  ├─ alembic.ini
│  │  ├─ requirements.txt
│  │  └─ .env                 当前后端运行配置，不提交 Git
│  ├─ admin\
│     ├─ index.html
│     └─ assets\
│  └─ deploy\windows\
│     ├─ install-server.ps1
│     └─ health-check.ps1
├─ config\
│  ├─ backend.env             后端共享配置和数据库连接，限制为管理员/System读取
│  ├─ my.ini                  MySQL 配置
│  └─ mysql-root-password.txt MySQL 初始 root 密码，妥善备份后可移走
├─ data\
│  ├─ mysql\                 MySQL 真实数据，绝对不能随意删除
│  └─ uploads\               报修图片、维保 PDF、导入文件
├─ infra\
│  ├─ mysql-8.0.36-winx64\
│  └─ nginx-1.26.3\
├─ venv\                      Python 服务器虚拟环境
├─ scripts\
│  ├─ start-backend.cmd
│  └─ start-nginx.cmd
├─ logs\
│  └─ backend.log
├─ backups\                  每次部署前自动备份上一版本代码，不备份密钥
└─ downloads\                首次安装下载的软件包
```

另外保留上传包：

```text
C:\deploy\elevator-release-年月日-时分秒.zip
```

确认新版本运行正常后，可手工删除过旧 ZIP 和过旧的 `backups`，但不要删除 `data`、`config`、`current`。

## 10. 后续更新代码

修改代码后重新执行本地打包：

```powershell
cd "E:\bishe27\小程序\电梯维修"
.\deploy\windows\build-release.ps1 -SkipInstall
```

上传新的服务器 ZIP，再重复第 6 节的一键部署命令即可。脚本会：

```text
备份旧 current
保留 MySQL 数据
保留 uploads
保留数据库账号和配置
执行增量 Alembic migration
替换后台和后端代码
重启服务
重新健康检查
```

`app.seed` 本身会在已有用户数据时跳过，但正式业务开始录入数据后，更新时建议删除命令末尾的 `-SeedDemoData`。

## 11. 正式上线前还差什么

当前一键脚本部署的是**公网演示/联调环境**，配置仍为：

```text
AUTH_MODE=mock
PAYMENT_MODE=mock
STORAGE_BACKEND=local
NOTIFICATION_MODE=mock
```

原因是当前源码尚未实现正式微信登录、正式微信支付、正式订阅消息和 COS Adapter。不要仅把环境变量改为 `wechat` 或 `cos`，否则不会凭空获得正式能力。

真正上线还需要依次完成：

1. 购买或准备域名。
2. 中国大陆服务器域名完成 ICP 备案。
3. DNS 添加 A 记录指向服务器公网 IP。
4. 申请 SSL 证书并给 Nginx 配置 443/HTTPS。
5. 微信公众平台配置 `request`、`uploadFile`、`downloadFile` 合法域名。
6. 把 `miniprogram/.env.production` 中的 API 地址改成正式 HTTPS 域名。
7. 实现并验证正式微信登录 Adapter。
8. 实现微信支付下单、服务端回调验签、金额校验、幂等和主动查单。
9. 实现正式订阅消息和对象存储 Adapter。
10. 微信开发者工具上传代码，提交体验版/审核/发布。

腾讯云说明：中国大陆服务器使用域名对外提供网站服务时需完成备案，并配置 DNS 解析；正式 HTTPS 应开放 443 并安装证书。  
参考：[腾讯云域名、备案、DNS 与 HTTPS说明](https://cloud.tencent.com/document/product/1207/60423)、[Windows Nginx SSL 证书部署](https://cloud.tencent.com/document/product/400/94492)。

## 12. HTTPS 文件放在哪里

从腾讯云 SSL 证书控制台下载 Nginx 类型证书，服务器建议放：

```text
C:\elevator-service\config\ssl\你的域名_bundle.crt
C:\elevator-service\config\ssl\你的域名.key
```

然后在：

```text
C:\elevator-service\infra\nginx-1.26.3\conf\nginx.conf
```

增加 443 `server` 配置，并把 80 跳转到 HTTPS。腾讯云 Windows Nginx 文档要求证书目录不要包含中文或空格，本指南的目录满足该要求。  
参考：[Nginx 服务器 SSL 证书安装部署（Windows）](https://cloud.tencent.com/document/product/400/94492)。

## 13. 常见问题

### 13.1 `ls` 只看到 AppData 和 Favorites

这是因为当前位于 System 用户目录。执行：

```powershell
cd C:\elevator-service
Get-ChildItem
```

### 13.2 TAT 显示命令超时

首次部署需要下载 Python、MySQL 和 Nginx，把超时设置为 3600 秒。不要反复同时执行多个安装命令；先查看：

```powershell
Get-Content C:\elevator-service\logs\backend.log -Tail 100
Get-Service ElevatorMySQL
Get-ScheduledTask ElevatorBackend, ElevatorNginx
```

### 13.3 80 端口被占用

检查：

```powershell
Get-NetTCPConnection -State Listen -LocalPort 80 |
    Select-Object LocalAddress,LocalPort,OwningProcess
Get-Process -Id <上一步的OwningProcess>
```

安装脚本不会擅自关闭 IIS 或其他网站服务；确认无用后再手动处理端口占用。

### 13.4 管理后台打开但 API 报错

检查：

```powershell
Invoke-RestMethod http://127.0.0.1:8010/api/health
Invoke-RestMethod http://127.0.0.1/api/health
Get-Content C:\elevator-service\logs\backend.log -Tail 100
```

第一个失败通常是 FastAPI 问题；第一个成功、第二个失败通常是 Nginx 配置问题。

### 13.5 能用 IP 打开，微信小程序却不能请求

IP 上的 HTTP 只用于第一次浏览器验收。微信小程序正式请求需要 HTTPS 合法域名，因此必须继续完成域名、备案、证书和微信公众平台域名配置。

## 14. 安全提醒

1. 当前仓库根目录曾出现包含服务器登录信息的排查文本。不要将该文件提交 Git、发送给他人或放进发布 ZIP；`.gitignore` 已增加忽略规则。
2. 如果服务器密码曾以明文出现在聊天、截图或代码仓库中，应在腾讯云控制台立即重置。
3. 不要公网开放 MySQL 3306 和 FastAPI 8010。
4. 不要把 `.env`、微信 AppSecret、APIv3 Key、商户私钥或 COS SecretKey 提交 Git。
5. 正式收款必须以服务端微信支付回调和主动查单结果为准，不能相信小程序前端“支付成功”回调。
6. 正式上线前先为服务器创建快照，并定期备份 MySQL 与 `data\uploads`。
