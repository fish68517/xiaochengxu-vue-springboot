加装电梯后期管理小程序【最终完整版功能需求单】

一、项目说明

用于旧楼加装电梯企业介绍、后期运维、缴费、报修、装修登记、公告通知、电梯每月维保记录查询的业主小程序。
配套电脑后台+手机移动端管理，功能简单实用、权限分级管理，适合小区长期运营管理。

二、业主小程序端功能

1、企业介绍

1. 独立菜单栏入口，内嵌我方自行制作的企业介绍H5页面

2. 无需后台编辑H5内容，仅提供上传/嵌入H5链接通道即可

2、一键缴费功能（核心）

1. 后台提前录入：房号、唯一住户编码、对应缴费金额

2. 业主通过编码+房号绑定房屋

3. 支持一户绑定多名住户，全家可共用查看、缴费

4. 在线微信缴费，支持多种缴费项目

5. 缴费完成后，业主可自主在线申请收据

6. 可查看全部缴费记录、待缴、欠费记录

3、电梯维保报修功能（核心）

1. 页面强制醒目提示：电梯困梯、紧急故障禁止小程序报修，直接拨打电梯现场救援电话，小程序只用于普通故障报修。

2. 业主报修填写：房号、文字描述、上传故障图片、联系人、电话

3. 提交后自动微信通知维修师傅+后台管理员

4. 师傅可上传维修进度、维修结果、完工照片

5. 业主可实时查看工单状态（待处理、维修中、已完成）

4、电梯每月维保记录查询（专属权限）

1. 后台支持维修师傅手动上传每月维保电子PDF单据

2. 上传单据时选择对应楼栋、对应电梯，绑定归档

3. 业主权限隔离：业主只能查看自己本栋电梯的维保记录，无法查看其他楼栋

4. 业主端可在线点开、浏览每一期维保PDF存档记录

5. 自动按时间排序，可查看历年所有维保存档记录

5、装修登记功能（含押金提示）

1. 页面展示我方提供《装修须知》

2. 业主在线填写装修报备登记

3. 页面醒目强制提示：业主装修需缴纳电梯装修押金2000元，线上仅为登记报备，需线下到公司缴纳押金并签署装修承诺书，办理完成后方可进场施工

4. 所有登记数据后台可查看、跟进押金及承诺书办理状态

6、公告栏

1. 后台可发布、删除、置顶公告

2. 业主可查看电梯通知、缴费通知、维保通知、小区公告

7、个人中心

我的房号、我的缴费、我的报修、我的装修记录、我的楼栋维保记录、消息通知

三、管理后台功能（PC端 ）

1、企业介绍管理

支持后台录入/替换企业介绍H5链接，一键更新前端展示内容

2、报修工单管理

1. 所有报修工单实时展示

2. 管理员手动派单给维修师傅

3. 可跟进进度、修改状态、查询历史工单

3、收费项目管理

1. 后台批量录入房号、住户编码、自定义收费金额

2. 可新增、修改、关闭各类缴费项目（可单独增设装修押金项目）

3. 支持多种缴费方式

4、欠费预警 + 催收功能

1. 系统自动识别欠费住户，后台高亮预警

2. 支持后台一键发送催收通知提醒业主缴费

3. 可查看欠费明细、已缴明细台账

5、维保档案管理（PDF上传归档）

1. 后台专属入口：师傅可自主上传每月电梯维保PDF报告单

2. 上传需选择：楼栋、电梯编号、维保日期

3. 后台永久存档、可删除、可管理、可下载

4. 系统自动按楼栋区分数据，严格隔离业主查看权限

6、装修登记管理

1. 查看所有业主装修报备记录

2. 后台可标记：未交押金/已交押金/已签承诺书/已办结状态，方便跟进管理

7、公告发布管理

自主发布日常通知、公示、温馨提示

四、交付要求

1. 微信业主小程序

2. PC电脑管理后台

3. 支持师傅上传小程序 维保PDF、接单处理

4. 权限隔离：业主仅可见本栋维保记录

6. 支持嵌入自定义企业介绍H5页面

7. 全部功能调试正常、可直接上线使用
