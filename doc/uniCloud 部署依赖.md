# uniCloud 部署依赖

> 客户准备清单｜更新日期：2026-09-07

本项目包含客户 H5、客服/接单工作台和管理后台，后端采用 uniCloud 腾讯云服务空间。部署后可通过正式网址访问，无需保持开发电脑开机。

## 一、客户需要准备什么

| 项目 | 准备内容 | 用途 |
|---|---|---|
| 经营主体资料 | 营业执照、主体名称、负责人及联系方式 | 账号实名、域名备案、微信及支付申请 |
| DCloud / uniCloud 账号 | 完成开通所需实名，授权开发人员协作 | 管理云空间、部署系统 |
| 腾讯云服务空间 | 开通满足项目需要的付费空间，保留可用余额 | 运行后端、数据库和文件存储 |
| 正式域名 | 购买域名并完成实名；按腾讯云要求完成备案或接入备案，提供域名解析权限 | 客户、员工和管理员在线访问 |
| HTTPS 证书 | 覆盖所使用域名的有效证书，可由开发人员协助申请 | 加密访问及微信对接 |
| 品牌和运营资料 | 平台名称、Logo、商品图片、价格、客服电话、管理员名单 | 配置正式业务内容 |

账号和域名建议归客户主体持有，通过协作授权提供部署权限；密钥通过安全渠道交接，不放入公开文档。

## 二、使用微信功能时，还需准备

| 功能 | 需要准备 |
|---|---|
| 发布微信小程序 | 小程序账号、AppID，以及对应类目要求的认证、备案和审核材料 |
| 微信客服发送下单链接、微信内授权 | 与当前接入方式匹配的微信账号及接口权限、AppID、AppSecret，配合配置授权域名和消息回调 |
| 微信真实收款、退款 | 微信支付商户号、对应支付产品权限、与应用的绑定关系及 API 证书/密钥，配合配置支付域名和回调地址 |

仅部署网页供浏览演示时，不必先发布小程序；正式交易功能启用前，需要完成对应微信权限申请与联调。

## 三、本项目怎么部署

- **前端：** 三端网页发布到静态托管，分别提供客户入口、工作台入口和管理入口；可通过域名及路径区分。
- **后端：** 部署现有业务云函数、微信消息回调和定时任务，初始化数据库、索引及云存储。
- **环境：** 测试环境与正式环境隔离；配置正式域名、HTTPS、访问白名单、密钥、备份和告警。
- **验收：** 先在测试环境完成手机访问、登录、订单及已开通微信功能联调，再安排正式发布。

本方案的业务运行通常无需另购传统服务器或 MySQL 数据库；备案所需资源资格须另向接入服务商确认。托管空间数量与套餐根据品牌数量、访问量和域名配额确定。

## 四、费用与交付分工

客户负责账号申请、主体资料、域名备案、微信审核及相关服务费用；开发方负责代码部署、域名配置、系统初始化和功能联调。

持续费用主要包括域名续费、云空间、存储和流量；微信认证、支付手续费等按实际开通服务计费。具体金额以服务商开通页面为准。

当前项目已完成商用 Batch 0～2 的代码及本地验证，真实 uniCloud 和微信环境尚待部署验收；完成云部署后，仍需按商用计划完成后续工作才能正式运营。

## 五、域名说明

正式运营应绑定自有域名，不使用平台测试域名。腾讯云域名绑定需要腾讯云接入备案信息；新空间的绑定入口及托管访问开关以当前控制台为准。参考：[uniCloud 网页托管](https://doc.dcloud.net.cn/uniCloud/hosting.html)、[域名绑定要求](https://doc.dcloud.net.cn/uniCloud/http)。
