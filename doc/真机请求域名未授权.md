# 真机提示 url not in domain list

日期：2026-09-13。

## 结论与操作

截图是小程序首页云请求被微信合法域名校验拦截，尚未进入支付流程。不是证书、APIv3 密钥、支付 AppID 绑定或支付回调问题。

本地小程序 AppID 为 `wxe40bb897376601cc`，使用阿里云 uniCloud。请登录这个小程序的微信公众平台（不是服务号后台），进入“开发与服务 → 开发管理 → 开发设置 → 服务器域名”，在 **request 合法域名**新增：

```text
https://api.next.bspapp.com
```

不要填写 `/client`，不要放在“业务域名”栏，也不要删除原有域名。此域名为 uniCloud 官方列出的阿里云云函数 request 域名，见[uniCloud 发行说明](https://doc.dcloud.net.cn/uniCloud/publish.html)。当前包 SDK 同时包含旧版 api.bspapp.com，但不能仅凭 SDK 字符串认定它被使用；若网络日志明确显示该旧域名也被拦截，再核查空间版本及对应配置。

保存后，在微信开发者工具刷新项目域名配置，重新编译并生成预览二维码；手机退出旧小程序后重新扫码。验收时不要勾选“不校验合法域名”，否则模拟器会掩盖真机问题。当前 manifest 与生成的 project.config.json 中 urlCheck 为 false，可解释为何开发工具没有及早暴露此问题；它不代表微信后台已经授权。

## 三类域名不要混淆

| 用途 | 配置位置／地址 |
|---|---|
| 小程序请求阿里云函数 | 小程序服务器域名的 request：`https://api.next.bspapp.com` |
| 小程序 web-view 打开下单网页 | 小程序业务域名：`h5.qmhyjoy.com`，按微信要求完成校验文件验证 |
| 微信支付服务器发送回调 | 云函数 URL 化：`https://api.qmhyplayer.com/pay-notify`，不是本次首页云请求的域名 |

上传、下载合法域名从 uniCloud 空间总览取实际值，仅在有对应功能时配置；不要猜测存储域名。H5 的 uniCloud Web 安全域名与小程序 request 白名单也不是同一项。

## 代码处理与验证边界

已在客户请求层将此错误识别为 `MINIPROGRAM_REQUEST_DOMAIN_NOT_ALLOWED`，展示可理解的部署提示，并取消无效自动重试；不会绕过微信域名校验。微信后台的域名授权不能通过修改业务代码代替。
