可以，现在进入最后的 **“腾讯云服务器重启后自动恢复验收”**。这次测试的目标很明确：

```text
服务器重启
   ↓
不手工启动任何程序
   ↓
MySQL 自动启动
   ↓
4 个计划任务自动触发
   ↓
两个 FastAPI 自动恢复
   ↓
两套 Nginx 自动恢复
   ↓
萌宠 + 电梯全部可以正常访问/登录
```

这一次测试期间，**重启后不要手工执行 nginx.exe、uvicorn，也不要手工 `/Run` 计划任务**，否则就失去“自动恢复验收”的意义。

## 第 1 步：重启前最后确认一次

先分别检查两个后端：

```powershell
Invoke-RestMethod http://127.0.0.1:8000/health
```

萌宠应看到：

```text
status       : ok
environment  : production
database     : mysql
```

再执行：

```powershell
Invoke-RestMethod http://127.0.0.1:8100/api/health
```

电梯应该看到 `status=ok`、`database=mysql`。

再确认 7 个端口：

```powershell
Get-NetTCPConnection `
  -LocalPort 80,8081,8082,8083,8000,8100,3306 `
  -State Listen `
  -ErrorAction SilentlyContinue |
Select-Object LocalAddress,LocalPort,State,OwningProcess |
Sort-Object LocalPort
```

现在应该是：

```text
80      ✅
8081    ✅
8082    ✅
8083    ✅
8000    ✅
8100    ✅
3306    ✅
```

如果这两个 health 和 7 个端口都正常，就执行真正的重启。

---

## 第 2 步：正式重启腾讯云服务器

执行：

```powershell
Restart-Computer -Force
```

执行后当前 PowerShell/TAT 会断开，**这是正常的**。

然后不要立即访问网站。

### 等待约 60～90 秒

建议这次直接等：

```text
90 秒
```

因为 Windows Server 启动后还需要完成：

```text
Windows
 ↓
MySQL80
 ↓
FastAPI
 ↓
Nginx
```

这一整套初始化。

---

# 第 3 步：重新进入腾讯云 TAT

重新进入服务器后，**先不要执行任何启动命令**。

也不要执行：

```text
schtasks /Run
nginx.exe
uvicorn
Start-Process ...
```

我们只检查。

首先：

```powershell
Get-Service MySQL80 |
Select-Object Name,Status,StartType
```

理想结果：

```text
Name      Status    StartType
MySQL80   Running   Automatic
```

---

# 第 4 步：检查四个自动启动任务

执行：

```powershell
$taskNames = @(
    "PetLifeMall-API",
    "PetLifeMall-Nginx",
    "ElevatorRepair-API",
    "ElevatorRepair-Nginx"
)

Get-ScheduledTask |
Where-Object { $_.TaskName -in $taskNames } |
Select-Object TaskName,State
```

这里不用纠结 `Ready` / `Running`。

例如：

```text
PetLifeMall-API        Running
PetLifeMall-Nginx      Ready
ElevatorRepair-API     Running
ElevatorRepair-Nginx   Ready
```

完全可能是正常状态。

真正的验收标准是下面的端口。

---

# 第 5 步：最重要——检查 7 个端口有没有自动恢复

**不要运行任何启动命令。**

直接：

```powershell
Get-NetTCPConnection `
  -LocalPort 80,8081,8082,8083,8000,8100,3306 `
  -State Listen `
  -ErrorAction SilentlyContinue |
Select-Object LocalAddress,LocalPort,State,OwningProcess |
Sort-Object LocalPort
```

理想结果应该全部出现：

```text
80      Listen     ← 萌宠后台 Nginx
8081    Listen     ← 萌宠 H5

8082    Listen     ← 电梯后台 Nginx
8083    Listen     ← 电梯 H5

8000    Listen     ← 萌宠 FastAPI
8100    Listen     ← 电梯 FastAPI

3306    Listen     ← MySQL
```

### 这一步如果 7 个全部出现

说明：

> **服务器重启以后，所有核心服务都已经自动启动成功。**

这是本次验收最关键的一关。

---

# 第 6 步：检查两个 FastAPI

再电梯：

## 最终验收标准

只要最终达到：

```text
腾讯云服务器重启
        ↓
等待 60～90 秒
        ↓
无需人工启动任何程序
        ↓
3306              ✅
8000              ✅
8100              ✅
80                ✅
8081              ✅
8082              ✅
8083              ✅
        ↓
萌宠 /health       ✅
电梯 /api/health   ✅
        ↓
四个 Web 页面       ✅
        ↓
后台正常登录         ✅
```

那么这套服务器就可以认为具备了**重启自动恢复能力**。

你现在执行 `Restart-Computer -Force`，等待约 **90 秒**后重新进入 TAT。然后先只把这两组结果发给我：

```text
① 7 个端口检查结果
② 两个 health 检查结果
```

我们用这两组结果做最终验收。
