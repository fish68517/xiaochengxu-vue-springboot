# clientorder 参考资产与测试占位规则

## 资产规则

## 资产分类

### 界面文案资产

由页面组件直接展示的文字，包括公告、提示、商品标题、详情说明、按钮、订单状态和表单提示等。测试阶段统一读取 `../content-assets.js` 的“测试文案”循环占位。

### 图片资产

商品图、Banner、Logo、头像、功能图标及其图片内部的文字，图片内部文字属于图片资产组成部分，不纳入界面文案资产。测试阶段统一使用 `../placeholder-image.svg` 占位。

上线前必须分别全量替换正式图片资产和界面文案资产。

当前目录中的裁切图不直接作为正式发布资源，但将作为正式图片资产生成参考，用于保留构图、主体比例、色彩方向、裁切范围和版式关系。正式资源需依据这些参考重新生成或提供，并在上线前完成全量替换。

测试开发阶段新增或尚未提供的图片，统一使用：

- `../placeholder-image.svg`
- 白色背景
- 红色叉号

测试开发阶段新增或尚未提供的文案，统一从：

- `../content-assets.js`
- `TEST_COPY` / `clientorderCopy`

读取，统一显示“测试文案”循环占位。不得在页面中新增业务真实文案作为临时占位。
