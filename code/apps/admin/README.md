# 管理端（uni-admin）

基于 uni-admin 快速搭建，挂载到同一 uniCloud 腾讯云服务空间。

## 待接入
- 账号管理（客服/接单人员创建、启用/停用、接单权限）
- 商品管理（商品 CRUD、动态表单 schema 编辑、上架/下架、抽成配置）
- 取消审核（审核通过 -> 原路退款）
- 提现审核（通过/驳回，线下打款确认）
- 钱包冻结（仅冻提现 / 冻提现+冻接单）
- 数据看板（今日订单/待审核/待打款）

## 使用
在 HBuilderX 中新建 uni-admin 项目，将 `uniCloud-tcb` 关联到同一服务空间，本目录作为管理端扩展说明与 schema 来源。
