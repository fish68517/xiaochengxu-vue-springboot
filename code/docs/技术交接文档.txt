## 2. 依赖关系

**领域单一源**

- `packages/domain/src/*.js`(index.js / order-machine.js / wallet.js / commission.js / brand.js)
- → esbuild(`scripts/build-domain.mjs`)打包为 CommonJS
- → `uniCloud-tcb/cloudfunctions/game-service/lib/domain.cjs`(构建产物,文件头注明勿手改)
- → `scripts/verify-domain-sync.mjs`(重新构建后对比导出集合与抽样行为)

**云函数 game-service**

- `uniCloud-tcb/cloudfunctions/game-service/index.js`(action 路由 + BizError/toEnvelope 错误封套 + URL 化 /pay-notify)
- 调用 `lib/services.cjs`(全量 action 契约层)、`lib/auth.cjs`(鉴权/白名单/角色矩阵/会话)、`lib/repository.cjs`(仓储抽象+事务)、`lib/wechat-pay.cjs`(微信支付 API v3)、`lib/oauth.cjs`(小程序登录/网页授权)、`lib/reconcile.cjs`(对账补偿)、`lib/upload.cjs`(对象存储上传)、`lib/subscribe.cjs`(订阅消息下发)、`lib/domain.cjs`(领域构建产物)

**本地镜像**

- `packages/backend/src/services.js`(镜像全量 action)、`packages/backend/src/db.js`(内存 20 集合)、`packages/backend/src/token.js`(H5 token)、`packages/backend/src/wechat-signature.js`(验签)
- → `scripts/api-server.mjs`(HTTP 路由,开发/测试用)

**前端三端**

- `apps/client/src/api.js`、`apps/workbench/src/api.js`、`apps/admin/src/api.js`
- → HTTP(`scripts/api-server.mjs`,`VITE_API_BASE`)或 `uniCloud.callFunction('game-service')`
- 页面依赖本端 api.js 与 `brand.js`(client)、`common.js`(workbench)、`utils/redline.js`+`utils/csv.js`(admin)

**独立云函数 wechat-callback**

- `uniCloud-tcb/cloudfunctions/wechat-callback/index.js`(微信客服消息验签 + 自动下发 H5 链接)
- 调用 `lib/wechat-signature.cjs`(token/timestamp/nonce SHA1 验签)、`lib/handle-message.cjs`(parseBody + extractEnterTempSession)、`lib/wechat-api.cjs`(access_token + 客服消息下发)
- 内部调用使用 `timestamp + nonce + payloadDigest + HMAC-SHA256` 签名，`game-service` 通过 `system_nonces` 持久化防重放；禁止透传 `INTERNAL_SECRET` 原文（未配置密钥时 fail-closed）。

## 6. 关键链路动作序列表

**下单支付双通道**

1. 小程序 `miniLogin`(code2session 换小程序 openid → 建/取 customers → 签发 CUSTOMER 会话 token)
2. `h5Token`(CUSTOMER 会话,签发 H5 下单 token,绑小程序 openid;兜底渠道:wechat-callback 凭 INTERNAL_SECRET 以 system 模式调用,绑 productId)
3. web-view 打开 `H5_ORDER_BASE_URL/#/pages/h5-order/index?token=`(apps/client/src/api.js 第 5-6 行)
4. `getH5Product`(验 H5 token 签名/过期 → 返回商品)
5. 微信内:服务号网页授权 `oauthExchange`(code → 服务号 openid)
6. `createOrderFromH5`(验 token,写订单,绑 payerOpenid=服务号 openid)
7. `getPaymentParams`(payType=JSAPI → jsapi 参数由 WeixinJSBridge 拉起;payType=MWEB → mwebUrl 跳转)
8. `payNotify`(TRANSACTION.SUCCESS 幂等 + 条件更新 + 金额核对;已超时关单走 reconcilePaidButClosed 补偿退款)

**退款与追佣**

1. `requestRefund`(差额比例 ratio=1−实际/保底,写 refunds 待审批)
2. `approveRefund`(ADMIN,调微信退款 + 追佣 debitWallet,写 refunds/order_logs,事务)
3. `payNotify` REFUND.SUCCESS 回调(按 wechatRefundId 幂等,refunds→SUCCESS)
4. `refundSuccess`(订单 REFUNDING → REFUNDED)

**提现 7 态**

1. `applyWithdrawal`：SUBMITTED，实名 APPROVED + 周次数 + 起提 10 元，事务冻结余额；
2. `startWithdrawalReview`：REVIEWING；`approveWithdrawal`：APPROVED；
3. `startWithdrawalPayment`：PAYING；失败时 `failWithdrawalPayment`：PAY_FAILED，可重新开始出款；
4. `markWithdrawalPaid`：PAID，写 batchNo/transfer_records 且只扣一次冻结余额；
5. 审核阶段 `rejectWithdrawal`：REJECTED，释放冻结余额并通知。
