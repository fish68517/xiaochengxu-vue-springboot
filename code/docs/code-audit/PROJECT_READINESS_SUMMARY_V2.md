## 本轮形成的发布候选能力

- 留言对象权限和全部报表实现多品牌隔离。
- 支付、入池、指派、接单上限、提现、补单与异议窗口受统一配置控制。
- 员工管理覆盖 Worker/客服、账号状态、实名通过和带原因驳回，并校验员工品牌范围。
- 商品公开查询与管理查询分离；字典/VIP 使用可追溯软状态。
- 红线规则以领域包为单一源，并在云函数侧执行最终拦截。
- 客服待办统一由后端统计；接单池读取运行配置并提供新单声音和角标。
- 阿里云和腾讯云均有数据库索引清单，定时任务有可执行部署说明。
- `npm test` 当前 `255/255` 通过；Client、Workbench、Admin 三端 H5 构建均通过。

## 上线前强制 Gate

1. 在目标云空间上传本次云函数代码，并按 `docs/deployment/UNICLOUD_INDEXES.md` 创建索引。
2. 配置并验证 `system-runner` 三个定时任务，保存执行日志。
3. 使用真实微信商户、服务号和小程序完成支付、回调、退款及订阅消息闭环。
4. 在正式域名/CDN下完成手机与电脑浏览器矩阵回归。
5. 验证云函数配额、监控与告警，确认没有 `PrePayResourceExhausted`。
6. 完成人工测试记录后，再决定灰度与放量。

## 验证边界

本轮没有上传 uniCloud、发布 H5、调用真实微信支付或修改部署环境。自动化和构建通过只证明仓库代码可运行，不替代真实云环境验收。
